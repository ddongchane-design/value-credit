무엇을 하는 프로그램인가

사람이 사건번호를 하나씩 검색하던 일을 대신합니다

자동 조회

원장에 있는 사건을 하나씩 대법원 나의사건검색에 넣어 조회합니다. 보안문자(6자리 숫자)는 프로그램이 자동으로 읽습니다. 사람이 붙어 있을 필요가 없습니다.

변제현황까지

사건 진행내역(접수·금지명령·개시·인가·폐지)뿐 아니라, 상환계좌를 넣으면 변제 회차·미납 회차·회차별 변제예정금액·총변제예정금액까지 받아옵니다.

변동만 골라서

지난 조회와 비교해 달라진 사건만 따로 모아 보여줍니다. 폐지·면책 같은 종국 사건은 맨 위에 올라옵니다.

이어서 조회

1만 건이면 한나절이 걸립니다. 창을 닫거나 PC를 꺼도 진행분은 저장되고, 다음에 켜면 남은 건부터 이어서 합니다.

엑셀로 내보내기

현황·사건 목록·변동·실패 목록을 언제든 엑셀로 내려받습니다. 같은 파일이 프로그램 폴더의 OUTPUT\report에도 남습니다.

내 PC에만 저장

조회한 사건 내용은 어떤 서버로도 가지 않습니다. 관리용으로 보내는 것은 「어느 사무실이 언제 몇 건 조회했나」뿐이고 사건 내용은 포함되지 않습니다.

3

설치 — 5분

설치 프로그램이 아니라 폴더째 풀어서 씁니다

  1. 다운로드

    위 「구글 드라이브에서 받기」로 개인회생조회_1.0.0.zip을 받습니다.

  2. 차단 해제 — 압축 풀기 전에 꼭

    받은 개인회생조회_1.0.0.zip을 우클릭 → 속성 → 창 맨 아래 「보안」 줄의 ☑ 차단 해제에 체크 → 확인.

    이 단계를 건너뛰면 프로그램이 실행되지 않습니다. ZIP에 붙은 「인터넷에서 받은 파일」 차단 표시가 압축을 풀 때 안의 모든 파일로 번지기 때문입니다. 이미 풀었다면 풀린 폴더를 지우고, ZIP에서 차단 해제 후 다시 푸세요. 속성 창에 「차단 해제」 항목이 안 보이면 이미 해제된 상태입니다.

  3. 압축 풀기

    차단 해제를 마친 zip을 우클릭 → 압축 풀기. 풀린 개인회생조회 폴더를 쓰기 편한 곳에 둡니다.

    권장 위치 C:\개인회생조회  — OneDrive·구글드라이브 같은 동기화 폴더 밖에 두세요. 조회 결과에 사건 당사자 정보가 들어가므로 클라우드로 올라가지 않게 하는 편이 안전합니다. (동기화 폴더 안에 두면 프로그램이 경고를 띄웁니다.)

  4. 실행

    폴더 안 개인회생조회.exe를 더블클릭합니다. 잠시 후 프로그램 창이 열립니다. 바탕화면 바로가기를 만들어 두면 편합니다 (exe 우클릭 → 보내기 → 바탕 화면에 바로가기 만들기).

    「Windows의 PC 보호」 파란 창이 뜨면 → 추가 정보 → 실행. 코드 서명이 없는 프로그램에 Windows가 처음 한 번 묻는 것이고, 다음부터는 뜨지 않습니다. 백신이 격리하면 폴더를 예외에 추가해 주세요. 더블클릭해도 아무 창이 안 뜨거나 바로 꺼지면 2단계 「차단 해제」를 빼먹은 것입니다 — 폴더를 지우고 ZIP부터 다시 하세요.

  5. 라이선스 키 등록

    처음 열면 키를 묻는 화면이 전부를 덮습니다. 메일로 받은 키를 전부 선택해 복사(Ctrl+C)한 뒤 칸에 붙여넣고(Ctrl+V) 등록을 누릅니다. 키가 사무실 이름·만료일과 함께 등록되면 바로 현황 화면으로 넘어갑니다.

  6. 끝

    이제 원장을 올리고 조회하면 됩니다. 아래 사용 순서로 이어집니다.

4

사용 순서

처음 한 번은 ①→②→③, 그 뒤로는 ③만

  1. 원장 올리기 — 「조회 실행」 메뉴

    양식 받기로 빈 엑셀을 받아 5개 열을 채웁니다 (기존 원장이 열 이름만 맞으면 그대로 써도 됩니다). 새 원장 파일 선택…으로 올리면 확인 화면이 뜹니다.

    확인 화면에서 볼 것 — 조회 대상 건수 · 법원코드 없음(조회 불가) · 사건번호 오류 · 계좌 비어 있음(변제현황 못 봄). 숫자가 이상하면 취소하고 엑셀을 고쳐서 다시 올리세요. 괜찮으면 이 내용으로 반영.

    반영하면 이전 원장과 데이터는 백업 파일로 남고, 새 원장으로 처음부터 시작합니다.

  2. 50건만 시험 조회

    처음에는 50건만 시험 조회를 눌러 보세요. 2~3분 정도 걸립니다. 성공 건수가 올라가고 「실시간 기록」에 사건이 하나씩 찍히면 정상입니다. 실패가 많으면 원장의 법원명·사건번호를 먼저 확인하세요.

  3. 조회 시작

    조회 시작을 누르면 남은 건 전부를 돕니다. 건당 2~4초이므로 1,000건 ≈ 1시간, 10,000건 ≈ 8~10시간입니다. 예상 소요 시간은 버튼 위에 나옵니다.

    조회 중에 창을 닫아도 됩니다 — 조회는 계속 돌고, 창을 다시 열면 진행 상황이 그대로 보입니다. PC를 꺼도 진행한 만큼 저장되어 다음에 이어서 합니다. 중지를 눌러도 조회한 건은 모두 남습니다.

    한 바퀴가 끝나면 실패한 건을 자동으로 두 번 더 시도합니다. 그래도 실패하면 대개 원장 문제이며 「실패한 사건」 표에서 사유를 볼 수 있습니다.

  4. 결과 보기

    현황 — 관리 중인 사건 수, 오늘 조회한 수, 확인이 필요한 변동, 실패 건, 총변제예정금액.
    사건 목록 — 사건마다 접수·금지·개시·인가일, 상태, 회차, 미납, 변제금액. 법원·상태로 거를 수 있습니다.
    변동 — 지난 조회와 달라진 건. 종국(폐지·면책) → 미납 → 변제계획 순으로 봅니다.
    사건 찾기 — 사건번호 하나를 넣으면 변제현황·변동 이력·법원 진행내역 전체가 나옵니다.

  5. 엑셀로 내보내기

    각 화면 오른쪽 위 ⤓ 내보내기를 누르면 그 화면의 표가 엑셀로 내려옵니다. 같은 파일이 프로그램 폴더 OUTPUT\report에도 저장됩니다.

매일 쓰는 방법 — 아침에 프로그램을 열고 조회 시작만 누르면 됩니다. 어제 못 끝낸 건부터 이어서 돌고, 끝나면 변동 메뉴에서 달라진 사건만 확인하세요.

꼭 지켜 주세요

차단과 개인정보

조회 간격은 2~4초를 권장합니다. 그 밑으로는 내리지 마세요. 대법원 서버가 「너무 자주 조회한다」고 판단하면 사무실 인터넷 회선 자체를 며칠 막습니다. 막히면 보안문자를 아무리 잘 읽어도 조회가 안 되고, 프로그램은 차단 응답이 3번 쌓이면 스스로 멈춘 뒤 3일간 실행을 거부합니다. 2~4초는 연속 조회에서 문제가 없었던 값이며, 설정 → 조회 속도에서 바꿀 수 있습니다.

결과 폴더를 클라우드 동기화에서 빼 주세요. 프로그램 폴더 안 OUTPUT에 사건 당사자 정보가 들어갑니다. OneDrive 안에 두었다면 OneDrive 설정 → 계정 → 폴더 선택에서 그 폴더의 체크를 해제하세요. 가장 간단한 방법은 처음부터 C:\개인회생조회처럼 동기화 밖에 두는 것입니다.

보안문자 인식률이 떨어지면

설정 화면의 「최근 인식률」이 60% 밑으로 내려가면 대법원이 보안문자를 바꾼 것일 수 있습니다. 담당자에게 알려 주세요. 프로그램을 고쳐서 새 버전을 드립니다.

새 버전 알림

새 버전이 나오면 프로그램 위쪽에 띠가 뜨고 다운로드 버튼이 나옵니다. 받아서 압축을 푼 뒤 기존 폴더의 OUTPUT 폴더를 새 폴더로 옮겨 넣으면 조회 데이터가 이어집니다. 라이선스 키는 메일에 있으니 다시 등록하면 됩니다.

라이선스 만료

만료가 가까워지면 프로그램 위쪽에 안내가 뜹니다. 만료 후에도 유예 기간에는 쓸 수 있고, 그 뒤로는 조회가 막힙니다. 연장 키를 받아 설정 → 라이선스 → 키 다시 등록에 붙여넣으면 됩니다.

7

자주 묻는 것

실행했는데 아무것도 안 뜹니다

가장 흔한 원인은 ZIP 「차단 해제」를 안 하고 압축을 푼 것입니다. 풀린 폴더를 지우고, ZIP 우클릭 → 속성 → ☑ 차단 해제 → 확인 → 다시 압축을 푸세요. (설치 2단계 참고)

그게 아니라면: 처음 실행은 몇 초 걸릴 수 있습니다. 한참 기다려도 안 뜨면 백신이 개인회생조회.exe를 막았을 가능성이 큽니다. 백신 격리함을 확인하고 폴더를 예외에 넣어 주세요. 그래도 안 되면 폴더 안 OUTPUT의 최신 로그 파일을 담당자에게 보내 주세요.

「이 앱은 PC를 보호하기 위해 차단되었습니다」

Windows SmartScreen입니다. 파란 창에서 추가 정보를 누르면 실행 버튼이 나옵니다. 코드 서명 인증서가 없는 프로그램에는 항상 이렇게 묻습니다. 한 번 실행하면 다음부터는 묻지 않습니다.

조회 결과가 어디에 저장되나요? 서버로 가나요?

프로그램 폴더 안 OUTPUT에만 저장됩니다 (사건 DB cases.db, 내보낸 엑셀 report, 로그 파일). 서버로 보내는 것은 「어느 사무실이 언제 몇 건 조회했나」 하는 사용 기록뿐이고, 사건번호·당사자·금액 같은 사건 내용은 어떤 경우에도 나가지 않습니다. 설정 → 프로그램 → 데이터 폴더에서 폴더 열기로 바로 열 수 있습니다.

실패한 사건이 있습니다

대부분 법원 서버의 일시 오류라 다시 조회하면 됩니다. 조회 실행 → 실패한 사건 → 실패한 사건만 재조회. 두 번 더 해도 실패하면 원장의 법원명이나 사건번호가 틀린 것입니다. 「사유」 열을 보고 원장을 고쳐서 다시 올리세요.

원장을 갱신하고 싶습니다 (사건이 추가됐습니다)

조회 실행 → 새 원장 파일 선택…으로 새 엑셀을 올리고 반영하면 됩니다. 지금 버전은 새 원장으로 처음부터 다시 시작하며, 이전 데이터는 백업 파일로 남습니다. 기존 조회 결과를 유지한 채 추가분만 붙이는 기능은 다음 버전에 넣을 예정입니다.

회사 방화벽·프록시 환경입니다

safind.scourt.go.kr(대법원 나의사건검색)로 나가는 HTTPS(443)가 열려 있어야 합니다. 프로그램 자체는 127.0.0.1(내 PC 안)에서만 돌고 외부에서 접속할 수 있는 포트를 열지 않습니다. 관리 연결(사용 기록·새 버전 확인)은 script.google.com을 쓰며, 막혀 있어도 조회에는 영향이 없습니다.

프로그램을 지우고 싶습니다

레지스트리나 시스템 폴더를 건드리지 않으므로 폴더를 통째로 지우면 끝입니다. 조회 결과를 남기려면 OUTPUT 폴더만 따로 옮겨 두세요.
